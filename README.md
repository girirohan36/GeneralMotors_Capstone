## General Motors Capstone Project | McCombs School of Business
Powering the Future Through Smart EV Expansion using Advanced Analytics


## Capstone Overview
This **Business Analytics Capstone** project focuses on optimizing the location of **DC fast EV chargers** for **General Motors**, contributing to their vision of powering the future with smarter Electric Vehicle (EV) infrastructure. The project aims to advance **GM's** **Three Zeros** vision by identifying optimal locations for EV chargers to drive growth, adoption, and sustainability in the electric vehicle market.

## Key Features Working On 
- **Strategic Placement Analysis**: Identified 100 optimal locations using:
  - EV ownership trends
  - Demographic data analysis
  - Existing infrastructure mapping
- **Predictive Scoring Model**: Machine learning algorithm prioritizing locations based on:
  - Market growth potential
  - Profitability metrics
  - Sustainability impact
- **Interactive Visualization**: Dashboard features:
  - Heatmaps of charger placement recommendations
  - Real-time adoption rate projections
  - ROI forecasting tools

## Methodology

### Data Analysis & Modeling
- **Primary Data Source**: GM-provided data on EV ownership, existing charging infrastructure, and demographic trends.
- **Third-Party Data**: Open-source data for traffic patterns, population metrics, and more, integrated to enrich the model.
- **Data Processing**: Data cleaning, KPI building, and feature engineering.
- **Modeling**: Training machine learning models to predict optimal locations for EV chargers.

### Deliverables:
- **Geospatial Model** for charger placement prioritization.
- **Interactive Dashboards** for easy visualization of the findings.
- **Actionable Insights** from data analysis and machine learning results.
- **Technical Documentation**: GitHub code repository and a detailed project report.
